# Features

Every change to this app, and every change we have considered. One row per
change, in both tables.

- **`specs/<N>-<title>/`** is where a change is designed and built. The folder
  stays after it ships — it is the record, not scratch.
- **Implemented** is the archive: what landed, when, and what it produced.
  `/implement` writes the row.
- **Candidates** is the backlog: things worth building, with enough of a note to
  pick one up cold. A candidate is not a commitment and carries no number until
  `/brainstorm` allocates one.

Numbers are never reused. `N` for a new change is one higher than the largest
in either table.

| [1](1-project-scaffolding/) | Project scaffolding | 2026-09-17 | Next.js 16 + TypeScript + Tailwind v4 + Vitest, deployable on Vercel defaults. The enforcement floor shipped whole: five generated ESLint import zones each watched to reject and accept, the design system's five role folders with a closed `Space` scale held by `tsc`, `src/lib/snippets/` with the words of the app, and a placeholder landing route and `not-found`. 48 tests. Produced [ADR 0002](../docs/adr/0002-zones-are-proven-against-real-fixtures.md) and [ADR 0003](../docs/adr/0003-user-facing-text-lives-in-snippets.md). D5 was graded **partly** and deferred to the first feature route: the guard allowed by default and named the three shapes it rejected, so a string reached through a local constant or an expression container walked past it. V3 was that route, and it made the hole wider than recorded — every word in the app moved into `src/features/panel/`, which the guard never read. A raw `Funky Drummer` planted in `Nameplate.tsx` on 2026-09-17 left 654 tests passing and lint at exit 0. Closed the same day by `inlineWords.test.ts`, which replaces `src/app/routes.test.ts` at the repo root, walks both trees and inverts the premise: every letter-bearing string literal is a violation unless it sits in a named position — a structural prop, a font-config key, a module specifier or a directive. All nine mutants from V1's third verification round die against it. Amended [ADR 0003](../docs/adr/0003-user-facing-text-lives-in-snippets.md) a third time. **D5 done.** |
| [2](2-a-reword-never-fails-a-test/) | A reword never fails a test | 2026-09-16 | `npm test` now runs two Vitest projects: `suite`, and `reword`, where `@/lib/snippets` resolves to a generated module whose every string has become `«reworded:notFound.body»`. A test that copied a word passes `suite` and fails `reword`, so the rule is proven rather than reviewed. A probe first measured that the rule held only by luck — the old string guard missed a partial quote and never read the repo root, and two planted violations sat in a green suite of 53 tests. `snippets.test.ts` is demoted to a fast advisory. Amended [ADR 0003](../docs/adr/0003-user-facing-text-lives-in-snippets.md), whose "both are enforced" was false, and [ADR 0002](../docs/adr/0002-zones-are-proven-against-real-fixtures.md), which gained the constraint the second project uncovered: a structural test that writes to the tree cannot run concurrently with itself, held by `sequence.groupOrder`. Three verification rounds each found a live mutant — a fixture race, a gate that served real words while every test passed, and a one-line `include` that silently disabled it. 136 tests. |
| [3](3-the-front-panel/) | The front panel | 2026-09-17 | The skeuomorphic panel from `app2.png`, in dark and light, with every control a working dummy and no audio. Twenty-one design-system primitives across all five role folders, and the first feature slice, `src/features/panel/`. The look is a named surface vocabulary in `globals.css` — twenty CSS variables split into a metal set the dark block redefines and a lit set it never touches, plus thirteen `@utility` recipes — and no component may name a colour, write a hex, use a `dark:` variant or read `prefers-color-scheme`. Produced [ADR 0004](../docs/adr/0004-the-look-is-a-named-surface-vocabulary.md). **The build was green and the panel was flat**: nothing in the repo renders a pixel, so V3 added Playwright and `.shots/shoot.mjs`, and `docs/testing.md` now says to take the shot before calling a visual bullet done. Four reversals followed from looking: the fader drags along its own axis, "CSS gradients only" gave way to inline `feTurbulence` noise and real fonts, the knob and fader thumb became SVG geometry with knurled teeth and turned grain, and the corner screws went. None of them touched a component contract — components only apply recipe names. Also fixed: `snippets.test.ts` matched copies by raw substring, so `panel.autoFeel` read as a copy of "Feel" and the word "nothing" as a copy of "thin"; it matches whole words now and finally enforces ADR 0003's design-system half. 600 tests. Two bullets were graded **partly** and both closed on 2026-09-17: D1's untested `KnobFace` and `ThumbFace` had in fact been covered before the change landed and the report was stale, and D4's TAP TEMPO flash — asserted with `tone="amber"` while the panel passes `tone="steel"` — now has the steel pair tested at component level and the flash tested at panel level. The suite reads 642 tests rather than 654: `inlineWords.test.ts` asserts over the whole tree in three tests where `routes.test.ts` ran ten per-file cases, and a per-file case count moved with the lint fixtures the walk passes through. |
| [4](4-the-kit/) | The kit | 2026-09-17 | 24 mono Ogg Vorbis one-shots in `public/samples/`, 236 KB, covering all 17 articulations of `docs/music.md` Part 3 as real recordings — **zero substitutions**. MuldjordKit (CC BY 4.0) for 13 rows, VCSL and FreePats World Percussion (both CC0) for the cross-stick, pedal hat, cowbell and shaker, so the pack carries exactly one attribution line. `src/lib/kit/` holds the frozen `Voice`/`Articulation` contract and a `KIT` manifest a structural test holds against the folder in both directions. The loudness rule in `docs/music.md` turned out to be unbuildable and was replaced mid-build: EBU R128 integrates over 400 ms behind a −70 LUFS gate, so a 100 ms rimshot reports the gate floor, and padding or momentary-max both read a short sample quieter than a long one at the same amplitude. Normalization is now onset-anchored RMS — −21.0 dBFS over 100 ms from the onset, target derived as `−1 dBFS − worst crest` — measured across the pack at −21.10 to −20.91. Produced [ADR 0005](../docs/adr/0005-samples-are-normalized-to-onset-window-rms.md) and [ADR 0006](../docs/adr/0006-the-kit-ships-as-ogg-vorbis-only.md), and amended `docs/music.md` twice. The musician found `Snare1`/`Snare2` correlate at r = −0.30 with identical lengths — top and bottom mic of one performance, not two takes — so alternating them as a round robin would change microphone every note; all four snare articulations come from `Snare1`. 654 tests. D1 was closed by ear on 2026-09-17: the backbeat does not crack and the kit is accepted without a rimshot, the four imports sit in the room, and `hihat.pedal` reads as a stick rather than a foot — left in place and carried as a candidate. |

## Candidates


| Candidate                                                                              | Why | Notes |
|:---------------------------------------------------------------------------------------| :-- | :-- |
| An in-app credit for the CC-BY samples | MuldjordKit is CC BY 4.0 and attribution currently lives only in `docs/samples.md`, which is the repo and not the app. | One line somewhere a user of the page can reach. The other two sources are CC0 and need nothing. Raised as a risk in V4's tech spec. |
| Headroom in the transport | `targetRmsDb` bounds one file, not the sum. Kick, snare and hat coinciding at gains 1.00 / 0.89 / 0.40 reach a theoretical 2.3×. | Wants a master trim in the signal path. Found while deriving V4's normalization target; it is the transport's problem, not the pack's. |
| A choke group for the open hi-hat | `hihat.open` rings 640 ms untrimmed, over four sixteenths at 96 BPM. V4 cut it to 300 ms, which is a compromise rather than a fix. | The real answer is the transport stopping the open hat when the next hi-hat note fires, as a real player's foot does. |
| Prove Ogg decodes on a real iPhone | V4 shipped Ogg Vorbis only, knowing caniuse measures the `<audio>` element and not `decodeAudioData`. | If iOS refuses it the app is silent on its target device. A probe page under `public/` answers it in twenty minutes; the fix is a second WAV pack and a format choice at load. See [ADR 0006](../docs/adr/0006-the-kit-ships-as-ogg-vorbis-only.md). |
| A foot chick for `hihat.pedal` | VCSL's `HiHat_Close` was taken for a pedal close from its name and from 6.8 dB more energy below 500 Hz than the stick stroke. On playback it has a stick attack on the front of it. | One filename in `src/lib/kit/manifest.ts`. `HiHat_HitOC` from the same folder is an open-close and probably carries the same attack; a source that names the stroke is the better bet — pjcohen [45668](https://freesound.org/s/45668/) or Skiba [93910](https://freesound.org/s/93910/), both CC0. Drop the file at `public/samples/hihat/pedal.ogg` and `scripts/normalize-samples.mjs` rewrites it to target. |
| Isolate the lint fixtures from the tree walkers | `eslint.config.test.ts` creates and deletes `src/features/zonefixture-*` while `snippets.test.ts` walks `src/`, inside the same project. A walk can still race a fixture's lifetime. | Predates V2 — V1 shipped it, V2 only made it frequent enough to see, and `sequence.groupOrder` only removed the cross-project half. Fix is a per-run fixture name or a walker that tolerates `ENOENT`. Shows up as an unrelated flake — seen once in eleven runs on 2026-09-17, as three failures in `src/app/theme.test.ts`, which walks `src/features/` for components naming a palette colour. `inlineWords.test.ts` tolerates `ENOENT`; `theme.test.ts`, `snippets.test.ts` and `structure.test.ts` do not. |
